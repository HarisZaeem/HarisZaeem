### 💻 Featured Projects

#### 📱 Scrapify — Final Year Project
A role-based mobile marketplace connecting scrap sellers, collectors, and admins across Pakistan — replacing Pakistan's informal "raddi" collection process with a structured, trackable digital workflow. Sellers list scrap with photos and GPS location, collectors get assigned pickups with live map navigation, and admins manage categories, base rates, and collector assignments from a central dashboard.

- Role-based access for **Seller**, **Collector**, and **Admin**, with a defined pickup status flow (`Pending → Assigned → On The Way → Completed`)
- Google Maps API integration for live location sharing, routing, and navigation between collector and seller
- Firebase Cloud Messaging for real-time push notifications on assignments and status updates
- Admin dashboard with analytics, PDF/Excel report export, base-rate management, and fake-listing/dispute reporting
- Ratings & rewards system between sellers and collectors
- Backend folder-based image storage with MongoDB Atlas for structured data

`React Native` `Node.js` `Express.js` `MongoDB Atlas` `Google Maps API` `Firebase FCM` `JWT Auth`

#### 📹 Real-Time Video Calling Web App

A browser-based peer-to-peer video calling application that allows users to join virtual rooms and communicate through live audio and video. The application uses WebRTC for direct media streaming between users and Socket.IO for real-time signaling, room management, and call negotiation.

* Room-based video calling where users can join using an **email address and room number**
* Real-time **audio and video communication** using the browser's WebRTC capabilities
* Peer-to-peer connection establishment using **WebRTC RTCPeerConnection**
* **Socket.IO-based signaling server** for managing room joins, call requests, call acceptance, and connection negotiation
* Displays connection status when another participant joins the same room
* Supports **incoming and outgoing video calls**
* Local camera and microphone access using `getUserMedia()`
* Displays both **local and remote video streams** during a call
* Uses public **STUN servers** to assist with establishing peer-to-peer connections
* Automatic WebRTC renegotiation to maintain communication when media tracks are added or connection details change
* React Router-based navigation between the **Lobby** and individual video-call rooms

`React.js` `Node.js` `Socket.IO` `WebRTC` `JavaScript` `React Router` `React Player`
